NotWired is a full-featured service that includes wired and wireless access. Before you can start using NotWired as a PQA application, you must signup at www.notwired.com. Once you have completed the signup on the NotWired web site, please make sure you choose a mobile login and mobile password/PIN in your user profile. This is you user ID and password to login to the NotWired system from this device.

Additional support is available at www.notwired.com/support.
