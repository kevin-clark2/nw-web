XML Skill Definitions

  • none - I don't know what XML is.
  • read a book - I have read a book on XML and understand how to use it.
  • novice - I have written some small XML applications and parsers.
  • skilled - I have used XML in commercial systems.
  • very skilled - I have used XML in lots of different commercial systems.
  • guru - I know everything about XML and its uses.
