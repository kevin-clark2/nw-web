HTML Skill Definitions

  • none - I don't know HTML.
  • read a book - I have read a book and seen those tags on the web pages.
  • novice - I know the basic tags but use a HTML editor to create pages.
  • skilled - I have designed pages on my own using tags.
  • very skilled - I have implemented commercial projects using HTML.
  • guru -  I have created commercial HTML pages and know how to debug HTML and JavaScript.
