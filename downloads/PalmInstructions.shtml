Palm Coordinator Installation Directions

1. DOWNLOAD THE SETUP.

2. FOLLOW THE DIRECTIONS BELOW EXACTLY AS THEY ARE WRITTEN.

Installation Notes:
The file Setup.exe that is downloaded from NotWired contains the NotWired applications, the NotWired conduit, the JSyncInstaller, and all ancillary files needed to setup the system When Setup.exe is executed, the JSync runtime environment, and the NotWired conduit are installed.

To Install the NotWired conduit:
Run the program Setup.exe. This will lead you through the installation and setup procedure for the NotWired conduit. It will also place the NotWired applications in a directory from where they can be installed on your PalmOS device.

IMPORTANT NOTES:
1. You MUST choose the directory where your Palm desktop tools are installed as the installation directory (E.g. c:\Palm).
2. After Setup.exe is complete you MUST stop and re-start HotSync.

Setup.exe will use the 'Install Tool' to setup Calendar.prc and Task List.prc for installation on your Palm device next time HotSync is run. If you choose not to install these applications during setup, you can follow the directions below to install these applications manually.

To Manually Install the NotWired applications for PalmOS:
1. Change to the directory where the Palm HotSync is installed (E.g. c:\Palm).
2. Execute InstApp.exe (can be found on the start menu Programs->Palm Desktop->Install Tool).
3. Click Add.
4. Choose the Calendar.prc file from the NotWired directory (E.g. c:\Palm\NotWired)

NOTE: While InstApp will allow you to select multiple applications for install, it is not recommended as it may cause problems with one application being loaded on top of another. SO, FOLLOW THESE DIRECTIONS EXACTLY AS THEY ARE WRITTEN.

5. Click Done.
6. Place your Palm device in the cradle.
7. Push the HotSync button. At this point, HotSync should start, and you should see the message "Installing handheld applications".
This operation takes approximately 45 seconds to complete.
The Calendar application should now be installed on your PalmOS device.
To Install the Task List application, repeat the above steps using Task List.prc in place of Calendar.prc.

Calendar Application Instructions:

The Calendar application is an enhanced version of the PalmOS native Datebook application. It uses the same underlying database as Datebook. Therefore, events created on the Calendar app will appear on the Datebook and visa-versa. The Calendar application contains a feature that allows you to invite people to events (meetings) created on your Palm device. When you create an event using Calendar, you can invite people to attend by clicking the 'Details' button and then clicking the 'Invite' button. You add invitees to your event by writing their e-mail address on the line labeled 'EMail' and then clicking the Add button. You can also use the 'Lookup' button to view the entries in your address book that have e-mail addresses (Note: Since an e-mail address is required to invite someone to an event, only Addressbook entries with e-mail addresses are shown). When you have completed your list of invitees, click done. If you look at the notes for this events, you will see something like the following:

<NotWired Invitees - do not edit>
someone@yahoo.com
other@hotmail.com
</NotWired>
