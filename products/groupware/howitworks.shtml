NotWired was designed for the Internet. It supports multiple organizations and multiple groups within one organization. A user can be a member of multiple organizations and unify their inbox, calendar and task list into a single view.

Key Architecture

100% Java. Written in 100% Java. NotWired is written in servlets with javascript. Interfaces to the engine include HTML, WML and PQA.
J2EE Support. Pages are defined in JSP and may be customized. FacadeBeans are provided to support workflow. A comprehesive business model supports modeling the application. Service layers may be implemented as EJBs to support complex deployments.
Supports Customization. Colors, fonts, layouts and more can be customized with templates and style sheets. The NotWired API is separate from the user interface to allow your developer's maximum flexibility to customize the framework.
Flexible Event types. NotWired supports regular events, invitee events and assignee events. These basic event types are extensible and flexible.
Layered Design. All data access is designed as access layers in the NotWired system. This will allow easy integration to legacy systems.
Pure Object-Oriented Framework. NotWired is more than an API. With the proper license, you can extend NotWired object models to meet any scheduling, calendar or workflow need.
