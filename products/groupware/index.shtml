Getting Started

NotWired has created a full-featured groupware framework that includes advanced messaging, scheduling, contact management and SFA. The frameworks include all JSP pages, EJBs, model code and services to support the applications.

Key Benefits

Faster development. Deliver group solutions to your user base quickly. NotWired has the infrastructure for security, calendars, member management, task management, workflow support and a flexible contact database on which to build a powerful and flexible system.
Easy Internet deployment. NotWired is designed to be a multi-user, Internet deployed solution. It is integrated with application security which enables you to administer user access from centralized user administration systems.
Easy customization. All applications in NotWired's groupware platform may be customized. Simple look and feel changes may be modified with an HTML editor. Complex workflow designs are created by combining modules and granular operations.
Support external users. All applications are designed to support workflow via e-mail. Anyone with email may become a user of the system or participate in designed workflows.
Integrated modules. NotWired's groupware platform integrates scheduling, calendars, notifications, inbox processing, contact management and email. All are completely integrated.
Integrated messaging. NotWired supports all multiple network standards and devices for you.
Device and browser independent. We have built the infrastructure to support HTML, WAP, Palm and PocketPC devices.
Adapt to any database. Using NotWired's datastore design pattern your may adapt the storage to one or many independent databases. All applications will all function correctly and independently of the database.
Source code. Source code is the most powerful framework a developer can user. NotWired is 100% Java source.
Multi-user system design. NotWired is designed to be a multi-user system. We have taken great care to make sure the system maintains data integrity for all shared data.
Easy to administer. All applications have application security integrated using standard J2EE security realms. Definitions exist to integrate a directory service or other access control database to NotWired applications.
