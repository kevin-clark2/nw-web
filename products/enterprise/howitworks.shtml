NotWired's application frameworks are built on open technology and standards. We utilize best practices for system and application design to deliver a robust, flexible and scalable frameworks.

Key Architecture

100% Java. Written in 100% Java. NotWired is written in servlets with javascript utilizing JSP and Struts for the controller framework. NotWired UI supports HTML, WML and PQA.
Unified programming model. Data services, frameworks, application models, security and controller workflows are all put together in a consistent manner to create applications.
JSP Pages, Tag and Script Libraries. NotWired uses standard JSP pages to deliver user interfaces for any application. Common components and tag libraries are provided to rapidly assemble applications. For more information about components and tag libraries click here.
Bean Support. NotWired provides the beans necessary to develop JSP screens. For example, a UserBean supports all information related to the current authenticated user. An OrganizationBean contains information related to organizations. Bean APIs are designed to maximize the capabilities of JSP and may be shared between application modules to maximize reuse.
Portlet Wrappers. Larger components, such as calendars, contacts, security administration and email may be delivered as portlets. NotWired adheres to the JSP-168 portlet specification and supports Portal Servers adhering to this specification. For more information about portlets, click here.
Layered design. All data access is designed as access layers in the NotWired system. This will allow easy integration to legacy systems.
Pure object-oriented. NotWired is more that an API. With the proper license you can extend NotWired object models to meet any application need.
Security. Support for custom database driven security and LDAP security structures. The application model supports the security to provide create, read, update and delete security to applications. The security system integrates with the programming model and rendering framework to create a consistent security implementation throughout all applications.
Supports customization. Colors, fonts, layouts and more can be customized with templates and style sheets. The NotWired API is also 100% removed from the user interface to allow your developers maximum flexibility.
