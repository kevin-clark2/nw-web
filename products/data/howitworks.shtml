NotWired's unique architecture allows you to quickly implement a propagation service into your site. It utilizes patent-pending store and forward technology with adapters to move data to any system or device available through the Internet or e-mail.

Key Architecture

100% Java. Written in 100% Java. NotWired is written in servlets with javascript. Interfaces to the engine include HTML, WML and PQA.
Supports customization. Colors, fonts, layouts and more can be customized with templates and style sheets. The NotWired API is also 100% removed from the user interface to allow your developer's maximum flexibility.
ASP or License Models. NotWired can support the ASP model to lower your upfront costs or you can license NotWired by the server.
Flexible event types. NotWired supports regular events, invitee events and assignee events. These basic event types are extensible and flexible.
Layered design. All data access is designed as access layers in the NotWired system. This will allow easy integration to legacy systems.
Pure object-oriented. NotWired is more than an API. With the proper license you can extend NotWired object models to meet any scheduling, calendar or workflow need.
