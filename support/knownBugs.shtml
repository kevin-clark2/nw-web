Known Issues

Problem with older Internet Explorer versions

Some older versions of Internet Explorer may cause problems with NotWired when applications pop up a new window. Also, there are some Java Script problems. Please download the latest version of Internet Explorer from http://www.microsoft.com to fix this problem

Top

Problem with printing background on Internet Explorer

When you print your calendar from NotWired, some Internet Explorer browsers may not print the background colors that appear on the screen. To fix this problem,

  •    Select Tools-> Internet Options from the menu.
  •    Go to the Advanced tab
  •    Make sure that the option 'Print background colors and images' is checked

Top

Problem with Netscape resizing

When Netscape resizes a window whose content is not cached, it resends a page requst to the server. Internet Explorer does not do this. The ramifications of this problem are:

  • The page that gets loaded will be the default page of the last module accessed from the navigation bar. This will interrupt any workflows that you were in.
  • Any form data that was being filled in at the time of the resize is lost.

Problem with javascript on Netscape Navigator browsers

Older versions of Netscape have some javascript bugs and will not work with NotWired. Please download the latest version of Netscape Communicator 4.7 from http://www.netscape.com to use NotWired.

Problem with using an older version of Internet Explorer on the Mac

Older versions of Internet Explorer on the Mac have some bugs and will not work with NotWired. Please download the latest version of Internet Explorer 5.0 from http://www.microsoft.com/mac to use NotWired.

Problem with changing page numbers on the Mac version of Internet Explorer

When changing page numbers on the Mac version of Internet Explorer, there may be problems when hitting the return key after changing the page number in the text field. Please use the left and right arrow icons instead, to move between pages.

Top

Problem with using the ENTER key in forms on the Mac version of Internet Explorer

There is a problem with Internet Explorer on the Mac when the ENTER key is pressed while in a textfield in a form, the form gets submitted erroneously. Please use the submit buttons on the page to submit the form.

Top

Problem with the 'Chooser Popup Window' hanging in Internet Explorer

There is a problem with the 'Chooser Popup Window' hanging in Internet Explorer. This problem arises when trying to select a large number of contacts from the chooser (approximately 300 contacts) and then trying to navigate within the chooser, i.e. switching to another letter in the index bar. This is a bug in Internet Explorer regarding memory usage in JavaScript. The workaround for this bug is to use Netscape instead of Internet Explorer, or by selecting smaller number of contacts at a time.

NotWired requires a minimum window width of 800 pixels. Please resize your window accordingly.

Problem with https downloads in Internet Explorer

There is a problem with Internet Explorer on MS Windows when downloading file using https. This is a known bug in Internet Explorer versions 5.5 and higher.

Problem with downloads crashing in Internet Explorer

There is a problem with Internet Explorer version IE 5.50.4807.2300 Update Versions: SP2; Q313675 and possibly other 5.5 versions as well, on MS Windows, when attempting to download the same file again and again. An example would be to download an email attachment by clicking on the download link, saving the file, and then repeating the same process a few more times, until the browser crashes. This problem does not occur in versions 5.0 and 6.0.
